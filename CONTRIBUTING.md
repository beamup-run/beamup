# Contributing

Thank you for your interest in BeamUp.

## Current repository phase

BeamUp implementation source has not been published yet. During this phase, we
welcome:

- corrections to public documentation
- questions about the planned open-core boundary
- concrete interoperability or portability use cases
- feedback about what developers need to inspect or verify

We are not accepting implementation pull requests yet. Issues or pull requests
that assume unreleased APIs may be closed until the relevant source and support
contract are public.

## Before opening an issue

- Read [README.md](README.md) and [OPEN_CORE.md](OPEN_CORE.md).
- Do not include credentials, tokens, private source, customer information, or
  exploit details.
- Use the private path in [SECURITY.md](SECURITY.md) for security concerns.
- Keep requests focused on one documented question or correction.

## Pull requests

Documentation pull requests should:

- explain the problem being corrected
- avoid claims about unreleased behavior
- preserve the distinction between planned source and published source
- use plain language and short examples

By submitting a contribution, you agree that it may be licensed under either
Apache-2.0 or MIT, at the recipient's option.

All participation is subject to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
